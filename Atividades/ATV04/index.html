O que é Front-end?

O desenvolvimentoFront-endestá relacionado à parte de uma aplicação que o usuário visualiza e utiliza diretamente.

Para desenvolver uma aplicação Web é importante compreender estrutura, apresentação e comportamento.

HTML não é responsável por criar o design da página.Sua principal função é estruturar o conteúdo.

O desenvolvimento Front-end utiliza diferentes tecnologias que trabalham em conjunto

As três principais tecnologias

  1. HTML—estrutura do conteúdo.
  2. CSS— apresentação visual.
  3. JS — comportamento e interatividade.

    4. HTML define a estrutura, CSS trabalha a apresentação e JavaScript permite adicionar comportamentos.

HTML — Estrutura da Web

O que é HTML?

HTMLé uma linguagem de marcação utilizada para estruturar documentos Web.

Um documento HTML é composto por elementos. Por exemplo, o elemento p representa um parágrafo.

Já o elemento a pode ser utilizado para criar um link.

Elementos HTML

Alguns elementos utilizados para estruturar uma página são:

  • h1 — título principal.
  • p — parágrafo
  • a — link.
  • img — imagem
  • ul — lista não ordenada

Atributos HTML

Os atributos fornecem informações adicionais sobre os elementos HTML

href
Define o destino de um link.
src
Define a origem de um recurso
alt
Fornece uma descrição alternativa para uma imagem
title
Fornece uma informação complementar
lang
Indica o idioma principal do documento.

HTML Semântico

HTML semântico significa utilizar elementos que representam o significado do conteúdo

Em vez de utilizar apenas div para toda a página, podemos utilizar elementos específicos para representar cada parte.

header
Representa o cabeçalho.
nav
Representa uma área de navegação
main
Representa o conteúdo principal
section
Representa uma seção do conteúdo.
article
Representa um conteúdo independente.
aside
Representa conteúdo complementar
footer
Representa o rodapé.

A tag div continua sendo útil para agrupamentos genéricos

Este conteúdo está dentro de uma div porque não possui uma função semântica específica

Semântica Textual Inline

O HTML também possui elementos utilizados para representar o significado de pequenos trechos de texto

Importância e ênfase

A tag strong indica grande importância.

A tag em pode indicarênfaseem determinada informação

A tag mark pode destacaruma informação importante

A tag small pode apresentar uma observação Esta é uma informação complementar.

Glossário Front-end

HTML
Linguagem utilizada para estruturar documentos Web.
CSS
Linguagem utilizada para definir a apresentação visual.
JavaScript
Linguagem utilizada para adicionar comportamento e interatividade.
Front-end
Área relacionada à interface com a qual o usuário interage.
Back-end
Área relacionada ao processamento e funcionamento interno das aplicações.
Elemento
Estrutura utilizada para representar determinado conteúdo HTML.
Atributo
Informação adicional associada a um elemento.
Semântica
Relação entre o elemento utilizado e o significado do conteúdo.
API
Interface utilizada para permitir comunicação entre sistemas.
URL
Endereço utilizado para localizar um recurso na Web.
